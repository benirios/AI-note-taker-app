# 🧠 MindNotes — Your AI Note Companion

MindNotes is a minimalist AI-powered note-taking app that helps you capture ideas and ask questions about your notes — like having a personal assistant that remembers everything you write.

---

## ✨ Features
- 📝 **Simple Note-Taking** — Quickly create, edit, and organize notes.  
- 🤖 **AI Q&A** — Ask natural language questions, and the app finds answers based on your stored notes.  
- 🔍 **Semantic Search** — Understands meaning, not just keywords.  
- 💾 **Local Storage** — Notes are stored privately and securely on your device.  
- 🧩 **Offline Mode (optional)** — Access and query notes without internet connection.

---

## 🛠️ Built With
- **Swift & SwiftUI** — For a smooth and native Apple experience.  
- **CoreML / Local LLM** — Enables offline question-answering.  
- **SQLite / Core Data** — For efficient local note storage.
